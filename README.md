# Drone Operations Dashboard

A Python dashboard foundation for monitoring and organizing drone operations. The project separates core logic, configuration, storage, communication, tools, and user-interface concerns for future development.

## Project Structure

- `core/` contains the central application logic.
- `config/` contains configuration handling.
- `comm/` contains communication-related modules.
- `storage/` contains local storage and persistence support.
- `tools/` contains operational utilities.
- `ui/` contains interface components.
- `logs/` contains runtime logs.

## Run Locally

```bash
python main.py
```

Use the project configuration files to adapt the dashboard to the target drone or simulator environment.
